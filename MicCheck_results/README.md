# Curated results

This directory contains the aggregate outputs from the standard MicCheck run.
It is intentionally limited to files that are useful for reviewing the study
without redistributing AMI audio, transcripts, or per-utterance features.

## Tables

- `dataset_summary.csv`: sample and corpus composition.
- `baseline_results.csv`: microphone, speaker, and lexical probe metrics.
- `bootstrap_intervals.csv`: bootstrap uncertainty intervals.
- `normalization_results.csv`: CMVN and CORAL comparisons.
- `invariant_results.csv`: paired-invariance objective sweep.
- `final_summary.csv`: compact headline results.

## Figures

The `figures/` directory contains the plots referenced from the project README.
Per-example plots are excluded because they are bulky and can reveal
utterance-level structure. They can be regenerated by running the notebook.

These artifacts should be interpreted with the limitations documented in the
top-level README, especially the small evaluation partitions and exploratory
counterfactual sample.
